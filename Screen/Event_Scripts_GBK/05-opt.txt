★ 通道映射（第 2/3 行和通常想的不一样，别改）
    第 1 行 G ← ADC0 ← vra0 / vdg0 / vp0    vev bit0 (值 1)
    第 2 行 C ← ADC2 ← vra2 / vdg2 / vp2    vev bit2 (值 4)
    第 3 行 E ← ADC1 ← vra1 / vdg1 / vp1    vev bit1 (值 2)
    第 4 行 A ← ADC3 ← vra3 / vdg3 / vp3    vev bit3 (值 8)

================================================================
  说明
================================================================

1. ★ AA 0B 帧（3 字节）：
      printh AA 0B
      prints vseq,1
   固件收到后把最近一帧 0x84 遥测写成 8 条变量赋值回传：
      vra0=... vra1=... vra2=... vra3=...
      vdg0=... vdg1=... vdg2=... vdg3=...
   注意 **vev由FPGA实际音频提交事件生成**（见 docs/01 §6 第 2 项，改 ESP32 只需 2 行）。
   加之前走 **`vusev=0` 的"强度 > 阈值"兜底判据**（第 ④ 步里已经写了），
   触发指示照样会亮，只是不如 FPGA 的锁定结果准。
   加上 `vev` 后把 `00-程序s.txt` 的 `int vusev=0` 改成 `1` 即可。

1b. ★ 在线判断看的是心跳 `vbeat`，不是读数有没有变。
   固件还没写 `vbeat` 时，`o_lk` 会一直显示「离线」—— 这是预期的，
   不代表通信断了。详见 docs/06-固件对接清单.md §1.2。

2. 触发指示靠改【背景色 bco】实现，不需要图片素材。
   ★ 前提：o_f1~o_f4 的 `sta` 属性必须是【纯色】。
     若选成"图片 / 裁剪"，bco 会被背景图盖住，改颜色无效。

3. `tim=100` 是必须的：vev 的锁存窗口就是 100 ms，
   轮询慢于它就会漏掉整次拨弦。

4. 第 ③ 步用 `if(vlink==1)` 把刷新包起来，是为了**失联时冻结显示**。
   否则链路断了以后，屏上会一直显示断链前的最后一组数，
   用户会以为是实时值 —— 这是最误导人的假象。

5. 本页需要显示的中文：光电调节、在线、离线、弦、读数、强度、阈值、
   触发、弦调节、预设、高级、保存、自检、返回
