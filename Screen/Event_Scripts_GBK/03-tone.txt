  Page 2 — tone（音色选择）  只有两种音色
  控件清单：docs/02-控件清单.md 第 3 节
  协议：docs/01-协议设计.md §9（AA 01 是固件已支持的老帧）
================================================================

本页不发 AA 0A。选音色用 3 字节的老帧 `AA 01 idx`。

双向同步需要本页新增一个非显示控件：定时器 `tm_sync`，
`tim=200`、`en=1`。定时器没有可见坐标，不占用页面布局。
在编辑器中建立这个控件，并粘贴下面的「tm_sync 事件」代码。

--------------------------------------------------------
【后初始化事件 Postinitialize Event】   ← 页面空白处 → 事件面板「后初始化事件」
--------------------------------------------------------
// 进页面先按 vatimbre 把高亮刷成正确状态
if(vatimbre==0)
{
  t_cur.txt="当前：音色 1"
  b0.bco=56784
  b0.pco=0
  b1.bco=22979
  b1.pco=65535
}
if(vatimbre==1)
{
  t_cur.txt="当前：音色 2"
  b0.bco=22979
  b0.pco=65535
  b1.bco=56784
  b1.pco=0
}


--------------------------------------------------------
【按钮 b0 弹起事件】 codesup —— 音色 1
--------------------------------------------------------
vatimbre=0
b0.bco=56784      // 自己被选中：浅木底
b0.pco=0          //            + 黑字
b1.bco=22979      // 另一个恢复：深木底
b1.pco=65535      //            + 白字
t_cur.txt="当前：音色 1"

// 下行帧：AA 01 00   共 3 字节，不加 FF FF FF
vidx=0
printh AA 01
prints vidx,1


--------------------------------------------------------
【按钮 b1 弹起事件】 codesup —— 音色 2
--------------------------------------------------------
vatimbre=1
b1.bco=56784      // 自己被选中：浅木底
b1.pco=0          //            + 黑字
b0.bco=22979      // 另一个恢复：深木底
b0.pco=65535      //            + 白字
t_cur.txt="当前：音色 2"

// 下行帧：AA 01 01   共 3 字节，不加 FF FF FF
vidx=1
printh AA 01
prints vidx,1


--------------------------------------------------------
【按钮 b_back 弹起事件】 codesup
--------------------------------------------------------
page main

--------------------------------------------------------
【定时器 tm_sync 事件】 tim=200、en=1
--------------------------------------------------------
// APP 改音色后，ESP32 写 vatimbre；当前页面也需要按它刷新。
// 本事件不发送 AA 01，避免把回显变成新命令而造成回路。
if(vatimbre==0)
{
  t_cur.txt="当前：音色 1"
  b0.bco=56784
  b0.pco=0
  b1.bco=22979
  b1.pco=65535
}
if(vatimbre==1)
{
  t_cur.txt="当前：音色 2"
  b0.bco=22979
  b0.pco=65535
  b1.bco=56784
  b1.pco=0
}


================================================================
  帧结构
================================================================

  printh AA 01        →  发出 AA 01
  prints vidx,1       →  发出 vidx 的低 1 字节（0 或 1）
  ----------------------------------------------------------
  合计 3 字节：  AA 01 00   或   AA 01 01

固件侧：screen_link.cpp 的 aaFrameLen(0x01)=3，第 3 字节即收帧，
分发到 onTimbre(idx)，idx 会被 &0x03 限制在 0~3。

★ 不要追加 `printh ff ff ff`。
  固定长度收帧已经能正确分帧，多出来的 3 个字节只会被丢弃，
  或者和下一帧粘在一起变成一条"未识别帧"。


================================================================
  ★ 关于「试听」按钮
================================================================
原设计的 b_test（试听）**已删除**。原因：

  · 固件里没有"播放测试音"的命令。screen_link.cpp 认识的子类型只有
    0x01 音色 / 0x02 预留 / 0x03 开机动画满值 / 0x04 校准页 / 0x0A / 0x0B。
  · AA 04 是【校准页】命令，跟试听无关，别用它。

想试听直接拨弦即可 —— 光电管会触发发声，这是本项目的正常工作方式。
若一定要按键试听，需要固件加命令，记在 docs/01-协议设计.md §6 待补清单里。


================================================================
  ★ 选中高亮的实现要点（TJC 没有"选中态"属性）
================================================================
1. 按钮的 `sta` 属性必须是【纯色】。若选成"图片 / 裁剪"，
   `bco` 会被背景图盖住，脚本改颜色一点反应都没有 —— 这是最常见的坑。
2. 面板里只设初始色：b0 和 b1 都设 `bco=22979`（深木底）+ `pco=65535`（白字）。
3. 运行时切换靠两处脚本（本文件已写好）：
   · 页面【后初始化事件】→ 进页面时按 vatimbre 把高亮刷成正确状态
   · 每个按钮【弹起事件】→ 自己点亮 (bco=56784 / pco=0)
                              另一个恢复 (bco=22979 / pco=65535)
4. 同一套写法还用在 opt 页的触发指示、preset 页档位按钮、
   gain 页选弦按钮、adv 页选参数按钮、check 页结果灯。


================================================================
  ★ 中文编码
================================================================
本文件是 UTF-8 编码。
字库制作工具的【编码】选 **utf-8**，与本文件一致 —— 直接复制粘贴即可，无需转码。

若你的 USART HMI 版本按 ANSI 处理编辑器内容（粘贴后乱码），
则改用 hmi_gbk/ 下的同名副本，并把字库编码改成 gb2312 或 gbk。
【两个编码必须配套，别混用】

本页需要显示的中文：音色选择、音色 1、音色 2、当前：、返回
只有 txt="..." 里的中文受影响，注释里的中文不用管。
