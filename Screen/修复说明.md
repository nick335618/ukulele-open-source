# 串口屏 BACK 修复

基于拇指琴与光晕钟版的 UkeStudio_Live.HMI。TJC3224T124_011，320×240 横屏，UART 115200。

第 13 页 page0 在原 BACK 图块上加了原生触摸热区 m0。位置 x=239、y=201，宽 67、高 31。保留原有页面绘图和分析订阅。热区的弹起事件为：

```text
printh AA 2D 53 03 7D
page main
```

原版 ESP32 已识别停止帧 0x53/0x03，可停止发送屏幕绘图命令。屏幕自己执行返回主页。只更新本目录 UkeStudio_BackFix.tft 即可应用此修复。

USART HMI 1.68.1 编译 0 错误、0 警告。离线模拟器两次从主页进入默认波形视图，再点击 BACK，均回到主页。未烧录实体屏幕。
