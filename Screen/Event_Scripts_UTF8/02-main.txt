// ===== ⑤ 请求一帧实时数据 =====
//   主页不显示读数，但**必须请求** —— 否则 vra* 不刷新，
//   下面的在线判断会把"链路正常"误判成"离线"。
//   代价：3 字节 / 300 ms ≈ 0.01% 带宽，可以忽略。
printh AA 0B
prints vseq,1
vseq=vseq+1
if(vseq>255)
{
  vseq=0
}

// ===== ⑥ 链路状态 =====
//   ESP32 不主动报"我在线"，只能看它有没有在刷 vra*。
//   4 路 ADC 都有本底噪声，帧一停就和上一帧一样，所以用「和」比较：
//     和变了 → 收到新数据 → 在线
//     连续 10 拍（3 秒）不变 → 判离线
// ESP32 每收到一次 AA 0B 就把 vbeat 写成新值
if(vbeat!=vbeatLast)
{
  vbeatLast=vbeat
  vbeatAge=0
  vlink=1
}else
{
  vbeatAge=vbeatAge+1
  if(vbeatAge>15)
  {
    vlink=0
  }
}

if(vlink==1)
{
  m_lk.txt="在线"
  m_lk.bco=22979
  m_lk.pco=2016
}else
{
  m_lk.txt="离线"
  m_lk.bco=63488
  m_lk.pco=0
}

================================================================
  说明
================================================================

1. ★ 定时器节拍 `tim=300` 是为了省电省带宽；
   但链路判断依赖 ESP32 回的心跳 `vbeat`，所以 300 ms 也是它的探测周期。
   `vbeatAge>15` => 15 × 300 ms = **4.5 秒**判离线。
   若要更快发现断链，把 `tm0.tim` 改成 150（超时变成 2.25 秒），
   或把 `if(vbeatAge>15)` 改小。

1b. ★★ 判在线用的是**心跳** `vbeat`，不是"比较 ADC 读数之和"。
   ESP32 每收到一次 `AA 0B` 就把 `vbeat` 写成新值（+1 或随机都行）。
   旧方案比"四路读数之和有没有变"是不可靠的：环境稳定的时候
   读数可能几十拍都不变，会被误判成离线。

2. `page` 必须是事件代码的**最后一句**，后面不能有别的语句。

3. 所有 int 变量不加 `.val`（见 00-程序s.txt 说明 1）。

4. 中文编码：字库工具【编码】选 **utf-8**，与本脚本文件一致，直接复制粘贴。
   只有 `t_tone.txt="..."` 这类字符串里的中文受影响，注释不用管。

5. 本页所有 `txt=` 赋值都要在**第一行**把 `txt_maxl` 设够
   （本页最长文案「自检未通过」5 个汉字 = 10 字节 UTF-8，
   加上变化余量，`txt_maxl=16` 够）。
