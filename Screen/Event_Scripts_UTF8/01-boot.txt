================================================================
  Page 0 — boot（开机动画）
================================================================

【后初始化事件 Postinitialize Event】   ← 页面空白处 → 事件面板「后初始化事件」
j0.val=0
t2.txt="启动中"
tm0.en=1


--------------------------------------------------------
【定时器 tm0 事件】  tim=50, en=1   ← 单击选中 tm0 控件 → 事件面板「定时器事件」
      方案 A：进度条动画（零素材，默认）
--------------------------------------------------------
// ★ tim 在【属性栏】里设，不写在脚本里。TJC 硬限制 50~65534，
//   写 40 会被夹到 50（或直接报错），所以这里用 50。
// ★ 步长从 3 改成 4：25 拍 × 50ms ≈ 1.25 秒，和原设计的 1.36 秒手感一致。
// ★ 不要写 j0.val+=4 —— TJC 不支持 += 这类复合赋值，必须展开
j0.val=j0.val+4
if(j0.val>=80)
{
  t2.txt="就绪"
}
if(j0.val>=100)
{
  j0.val=100
  tm0.en=0
  page main
}


================================================================
  方案 B：图片序列动画（美化升级，需准备素材）
================================================================
准备 20 张 320×240 的图片，导入为 pic 0 ~ 19。
把页面上放的【图片控件 p0】(0,0,320,240) 的 pic 设为 0。

然后：
  1) 把 tm0 的 tim 改成 80（每帧 80ms）
  2) 用下面的脚本替换上面的【后初始化事件】和【tm0 事件】

【后初始化事件】
p0.pic=0
sys0=0
tm0.en=1

【定时器 tm0 事件】   ← 单击选中 tm0 控件 → 事件面板「定时器事件」
sys0=sys0+1
if(sys0<20)
{
  p0.pic=sys0
}else
{
  p0.pic=19
  tm0.en=0
  page main
}

素材建议（尤克里里主题）：
  · 琴身轮廓逐笔绘出
  · 四根琴弦依次点亮
  · 音符从琴孔飘出
  · Logo 渐显
每帧 320×240，导出为 24 位 BMP 或 JPG，帧数控制在 20~30 帧，
Flash 只有 4MB，帧太多会放不下。
