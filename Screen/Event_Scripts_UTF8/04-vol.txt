★ 本页**不发任何二进制帧**。
  音量就是全局变量 vavol，固件会周期 `get vavol` 自己取走
  （screen_link.cpp 的 setVolume / requestVolume）。
  这是"屏上报、ESP32 采纳"的方向。

★ 固件里**没有"静音"这个量**，只有 vavol 0~100。
  所以静音 = vavol 置 0，并自己记一个 vmute 标志。

// ★ 从 vavol 读初值 —— 绝不能反过来把页面默认值写进 vavol，

// ---- 显示跟随 vavol ----
//   ESP32 也可能改 vavol（比如它自己恢复音量），所以周期刷一次
// 只在全局值变化时移动滑块，拖动尚未弹起时不抢回手指的位置。
if(n0.val!=vavol)
{
  h0.val=vavol
}
n0.val=vavol
j0.val=vavol
if(vmute==1)
{
  b_mute.txt="静音：开"

  b_mute.pco=0

  b_mute.bco=22979
  b_mute.pco=65535

if(vt2>0)
{
  vt2=vt2-1

  {

  }

================================================================
  说明
================================================================

1. ★★ **不要写 `vavol-=5` / `vavol+=5`** ——
   TJC BASIC 的复合赋值运算符支持情况不明，而 `vavol=vavol-5` 是
   手册里明确支持的写法（单运算符，左到右无歧义）。**一律用展开写法。**

2. `h0.val=vavol` 必须写：`n0`/`j0` 会自动跟随 `vavol`，
   但**滑块的位置不会自己动**。用户点 `-`/`+` 或静音后如果不写这一行，
   滑块就停在老位置，和数字对不上。

3. 提示条 `t1` 用 `vt2` 计数实现 2 秒自动消失，
   所以 `tm0` 必须常开（`en=1`, `tim=300`），不能像旧版那样
   用 `tm0.en` 开关 —— 那样显示就不刷新了。

4. 音量改动**立即生效**，不需要"保存"。断电保留由固件侧负责
  （音量的持久化和光电参数是两套，见固件 main_app.cpp）。

5. 本页需要显示的中文：音量调节、静音：关、静音：开、已静音、
   已取消静音、返回、%
