四档预设 = `op=2`，`ch` 填预设号，ESP32 会把该档**全部17参数及模式均由FPGA真实回读**
一次下发，**并自动回读** => vp0..vp15 会全部刷新。

串扰抑制 = pid 16（首事件锁定窗），单位是 50 MHz 时钟数。
  ★ pid 16 读不回来（0x86 只覆盖 pid 0~15），屏侧自己维护 vp16。

================================================================
  说明
================================================================

1. ★★ 为什么 `p_cur` 要用回读来的 vp0/vp4 拼，而不是直接写死档位名？
   因为**按键成功 ≠ 参数生效**：
     · ESP32 会把越界值钳位（比如某档阈值超过 4095）
     · 链路断了，帧根本没到
   只改按钮颜色的话，用户会以为已经切档了。
   显示回读值才能暴露"其实没生效"。

2. ★ 字符串拼接的唯一正确写法：

      covx vp0,t_tmp.txt,0,0        ← 数值 → 文本
      p_cur.txt=p_cur.txt+" 阈值 "  ← 字符串 + 字符串 确认

   **不能**写 `p_cur.txt=p_cur.txt+vp0` ——
   官方 p.844 明说"数值变量不能跟字符串变量相加"，编译就过不了。

3. `t_tmp` 是**本页**的屏幕外中转文本控件（x=-99,y=-99），拼字符串前先 `covx` 转进去。
   ★★ 它【没有】`vscope` 属性 —— 文本控件是**页面私有**的，跨页访问会报错。
   所以 preset / adv / check 三个用到 `covx` 的页面，每页都要各放一个 `t_tmp`
   （名字都叫 `t_tmp` 就行，页面私有不冲突，脚本不用改）。
   `covx` 是覆盖写，每页一个就够，不需要每行配一个。

4. ★★ `vp16` **不应**每次进入页面时复位，只在上电初始化、加载预设和恢复出厂时更新。
   否则会把用户手动设置的 `first_lock` 覆盖掉 —— 用户点了其它窗口，
   离开页面再回来就被冲回默认值，按钮高亮也跟着错。

   新版pid16由FPGA实际回读，按钮不改实际镜像。
