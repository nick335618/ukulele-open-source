# 3.16.0（versionCode 68）

## 曲库与搜索
- 默认练习曲库扩充至 1,007 首；前三首为《茉莉花》《小白菜》《凤阳花鼓》，随后为《送别》及其他熟悉旋律，再排列古典主旋律。
- 保留原10首曲目ID及上次选曲恢复方式。新曲以精确时值UKS1 v2保存，休止与结束熄灯明确。
- 中文、拼音、首字母、重音/大小写容错、近似曲名；按难度、风格、BPM筛选；40首分批显示。
- 长按曲目查看编配、许可与来源；设置→关于→练习曲库与开源致谢。

## UI
- 合入用户 App.zip 的分组设置首页、带返回导航的独立详情页、设置插图和卡片样式。
- 现有72灯编辑、音频分析、调音器、跟弹、评分、AI聊天与导入入口保留；音频效果器纳入独立设置模块。
- Android原生对话框继续使用系统交互。

## AI
- 搜谱先查内置曲库，本地命中可离线试听并直接导入，未命中继续原有联网来源搜索。
- 近似匹配明确标注，需试听确认。不会按歌名编造未找到的曲谱。
- 本地曲谱文本支持精确时值无损校验，保留休止、重复音与连音；修复旧10首文本在AI检索中被当作二进制的问题。
- 超长文本不再静默截断后交给模型，改为明确提示分段。
- 保留现有照片/PDF逐页识谱、校对、输入法和语音修复；本轮未宣称提升复杂谱面的OCR准确率。

## 工程
- 不需要更新FPGA或ESP32；BLE协议保持兼容。离线曲库不新增网络依赖。
- 用原签名覆盖安装可保留本地曲库、回收站、成绩、设置和AI通道。请先覆盖安装，不必卸载。
- build_apk.ps1 默认版本3.16.0 / 68，修复带官方通道参数时ASCII目录也必须临时隔离构建的问题；源文件保留密钥占位符。
