# Ukulele Studio v3.13.0 / code 58

本版以用户提供的 v3.12.3 源码为基线，保留既有 AI 搭子、联网曲谱搜索、BLE 控制、灯阵、曲库/回收站、评分、试听、波形和频谱功能。当前说明优先于历史版本说明。

## 使用入口

- 「乐趣 → 每日挑战」：完整真实练习、命中音符和80分目标，经验等级与近7天练习记录。
- 「乐趣 → 音乐游乐场」：5题听音挑战、5轮节奏模仿；独立保存最高分。
- 真实评分结束后显示星级、经验和再次挑战；原有实际拨弦评分规则保持不变。
- 「AI曲谱助手 → 照片 / PDF」：32MB以内原谱，PDF每批选择连续1—6页。原文件随指引保存在本机曲库。
- 合适的TAB+配套五线时值先由本机识别，结构检查不通过再走AI。导入前可翻页对照原图、试听、改转录、重新解析、确认保存。
- 本机识谱速度暂按120 BPM，页面会明确提示；可修改转录中的BPM再重新解析。TAB原弦位、多音和重复音保留；明确时值用DURATIONS逐列记录；没有可靠时值的TAB标为节奏待校对。
- 编辑转录后，旧结果停止可导入，必须重新解析。缺页、问号、未知和弦、错误时值和超界指法不会被静默替换。MIDI用实际解析器校验。

## 验证与限制

完整构建与APK签名校验通过，沿用原应用签名。299项新增逻辑检查、82项导谱回归和原评分测试通过；真实谱面回归3301项断言通过，含10首、466个音高/起音对照及5种图像/渲染变化。

识谱模型不保证任意图片逐音准确。真实接口测试中，清晰简谱14音匹配、空白图片拒绝；整页混合谱仅靠AI曾识别错误，因此本版接入已有本机识别优先路线。《欢乐颂》最终导入链路的62个音高、62个起音、总时长及原弦位均与标注吻合。复杂反复、模糊图、复杂伴奏仍需校对，不会包装成自动正确的结果。五线谱AI路线目前提取主旋律，和弦路线受现有18个常用和弦库限制。

本轮按用户要求先交付软件；没有手机安装、真机界面或实物演奏验证。没有修改FPGA、ESP32、屏幕或BLE协议。

## 构建

运行本目录build_apk.ps1；默认版本3.13.0/58，JDK17、Android SDK34。需要保留原应用签名；官方AI渠道凭据沿用原私有构建配置，在构建阶段注入，不写回源码。工具目录tools/verify_v3130提供不联网的逻辑测试。

详细变更、校验值和测试记录位于App/Reports。v3.12.3及更早说明保留在HISTORY-before-v3.13.0.md，包含仅适用于旧版的门槛和数据，不代表当前行为。
