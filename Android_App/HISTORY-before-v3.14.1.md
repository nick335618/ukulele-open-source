# Ukulele Studio v3.14.0 / code 60

基于 D:\APP优化\App\Source\android_app 的 v3.13.1，改进粘贴简谱与照片/PDF数字简谱导入。音色、硬件协议、BLE、LED、频谱、曲库与已有趣味模块沿用；本轮未改 FPGA、ESP32 和屏幕。

- 自动分离中文说明、歌词与音符，保留嵌入的调号/拍号；密排数字分别读音，不吞掉歌词后紧接的首音。
- 支持多条减时线、低/高八度、附点、同音延音连线和明确的反复；不同音的连线不会强行合并。
- 数字谱照片先定位行；密排行按已有小节边界分成两块并放大，附上原始谱头。AI逐字读音符，本机补充符号位置提示；数量不一致或不确定时仅追加一次局部重读，仍不确定保留 ?。
- 原照片/PDF与识别分段分开保存，原谱浏览保持完整。混合谱型PDF回退到原有逐页识别流程。
- 照片主旋律稿默认按可见顺序，不展开反复，不纳入小字装饰音；结果页可以选择展开反复，复杂跳房仍需补全并校对。
- 超出乐器音域的简谱不再悄悄删音；点击“整首升八度”，重新生成可演奏指引。可恢复原八度。
- 粘贴文字没有减时线、时值不完整时明确标记；“小节均分草稿”是用户可选的练习节奏，并非恢复原曲节奏。含延音连线时须保留原时值校对。
- 保留3.13.1的试听真实状态、可停止、旧计时取消、应用确认与真实保存回调，识别后无需导出MIDI再导入。
- 新增“联网找完整谱 / 核对时值”：填写歌名与作者，搜索公开来源，查看来源链接或读取文本谱；显示调号、拍号与最多前256音的级数顺序线索，人工确认采用。可恢复联网前原稿。搜索摘要或只有编配介绍的页面不会被当作音符，图片/PDF谱需要从原网页取得后用相册识谱导入；本版没有自动抓取网页全部谱图。

覆盖安装 App/Install/UkuleleStudio-v3.14.0-debug.apk，不必卸载旧版。使用相同应用签名。
本地完整构建：build_apk.ps1（默认3.14.0/code60）；官方AI渠道凭据只注入本机暂存副本，不写回源码。可使用自己的渠道设置重新构建/运行。

离线回归：tools/verify_v3140/verify.py（简谱与已记录识别结果）、tools/verify_v3130/verify.py（导谱/评分）、tools/verify_v3131/verify.py（试听）。
