# 电量显示与独立包络交付版

App 3.19.3，适用于新板。覆盖安装沿用上一版签名。请成套更新本目录 FPGA 和 ESP32，再使用扩展包络调节。

## 本次改动

- 单音包络使用完整覆盖的独立页面。顶部“完成”固定，参数区可滚动，底部恢复按钮不会叠在主页导航上。
- App 首页最上方显示乐器电量。电池图形有填充电量条、百分比，充电及涓流时有闪电，停止充电后移除闪电。
- 串口屏主页右上方显示电池图形、百分比和充电闪电。ESP32 确认当前页为 main 后才绘制，触摸或切页时取消未完成的绘制。沿用 BackFix 屏幕工程。
- 离线可查看各音色的包络、选择音高并拖动预览。连接配套固件后，拖动直接发送，下一次起音使用新值。已发声的声部保持自己的原有参数。
- 四套音色分别维护 C4 至 D♯6 的 28 个音高设置。同音高跨弦共用该音色内的设置，各音色之间独立。4×28 共 112 组可全部自定义。支持恢复当前音、恢复全部，曲线停留在最后选定音，调节时实时更新。
- 起音时长有 0.50、0.67、0.80、1、1.33、2、2.67、4 倍八档。
- 拨弦激励有 25%、31%、38%、44%、50%、63%、75%、100% 八档。这是起音激励上限，使用原有激励等级进行调节。
- 琴体共鸣有 0.5、1、1.5、2 倍四档，适用于尤克里里和吉他。拇指琴和光晕钟使用各自的模态衰减结构，页面会说明琴体参数不适用。

## 包络模型

四套音色各有频率、模态激励和阻尼参数，实际包络随音色与音高变化。尤克里里与吉他使用各自起音表，拇指琴和光晕钟沿用现有引擎对应的起音及衰减实现。起音表部分共享并不表示声音包络完全相同。

图形根据原始起音与模态参数计算，并保持到下一次选音，是可交互的模型预览。图中原厂峰值为 100%，改变拨弦激励可以看到相对峰值变化。实时音频分析仍显示实际音频数据。

本版开放原链路中的起音速度、激励上限及琴体激励增益，原始频率、阻尼和自然衰减参数保留。12 声部、每声部最多 60 弦模态、8 个共享琴体模态、48,828.125 Hz 采样率和原 ROM 内容保留。

设备自定义保留到 FPGA 复位或断电。离线修改是本机预览，连接时以设备真实回读为准。

- Android_App 为对应源码和构建脚本。
- FPGA/Project/modal60/gv_host.gprj 为完整 FPGA 工程。直接运行同目录 Build.cmd，或在高云 IDE 中打开。
- Firmware/FPGA/gv_host.fs 为配套 ADA8 位流，资源和时序见 Verification/交付验证.md。
- FPGA/Reports 为布局布线、资源、50 MHz 时序、管脚和功耗报告。

- Screen 为现有 BackFix.HMI 与 TFT。本次电池和扩展包络组件由 ESP32 动态绘制，已经使用 BackFix 的屏幕可继续沿用它。

## 电量数据

百分比由乐器端电池电压估算，通过既有状态链路传输，与手机电量独立。状态缺失、读数无效或超时显示“—”或“--”，清空填充和闪电。百分比准确度仍由实际电量计、接线及电池标定决定。

## 串口屏

动态绘制基于交付的 BackFix 工程，主页 page ID 为 1，电池区域位于 x232–314、y29–50。音色页 ENV 可选音、切换起音、琴体和激励档位，并恢复单音或全部。没有重新编译新的 HMI/TFT。

## 协议

ENV 文本使用 ENV:操作,音色,MIDI,参数,请求序号。操作 0 读取，1 写入，2 恢复当前音色，3 恢复全部。参数低三位为起音档，中两位为琴体档，高三位为激励档，默认 235。

FPGA 0x25 子协议版本 4，载荷 6 字节。0x91 版本 4 用 12 字节回读目标音色、音高、参数、请求号及该音色的 28 位修改掩码。ESP32 的 BLE B5 版本 3 长度 14 字节，带校验。标准 20 字节 ATT 有效载荷可容纳命令与通知。

## 验证范围

安装包、ESP32 编译、App 自动化回归、RTL 默认音色 PCM 对照、扩展协议和读表验证见 Verification。硬件尚未烧录本交付版，充电实物显示、新板听感和屏幕操作需在设备上联调确认。
