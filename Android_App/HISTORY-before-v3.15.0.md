# Ukulele Studio v3.14.4 / code64

本版增加 App 内不限站点的谱页搜索，自动解析没有候选时继续展示网页来源，明确区分网页与可演奏音符。继承 v3.14.3 的 APK 内部路径修复，以及聊天输入、中文离线语音、真实时值、多音灯光指引、评分、曲库、试听和练习功能。本版不需要改 FPGA、ESP32 或屏幕固件。

- 消息滚动不再转移输入焦点；点击输入框可退出收音、保留草稿并输入。
- 麦克风权限等待真实授权结果。系统语音服务不可用时，使用随包提供的 Vosk 中文离线识别；首次需要后台解包和加载模型。再次点击麦克风结束收音，关闭对话取消会话，旧回调不会覆盖新输入。
- 回复朗读以 TTS 实际回调结束为准；连续对话在前台、授权后运行，退出或朗读失败会停止。
- 找谱提供百度、必应浏览器搜索，不限制谱站；可返回粘贴链接或导入下载的 MIDI、PDF、图片。浏览器搜索无需 AI 渠道配置；AI 转录仍需要配置。App 内自动找 MIDI 的通用阶段也不再只接受固定站点。
- 搜索结果不是乐谱本身；读取、试听、校对后再入库，当前识别稿不会被搜索摘要自动覆盖。“搜索谱页（不限站点）”展示最多六个来源，需要 AI 搜索渠道；百度、必应按钮直接打开浏览器。图片谱、PDF、登录或付费谱应从原网页合法取得后导入。

## 构建

使用 build_apk.ps1，默认 3.14.4/code64。该脚本使用 JDK17、Android SDK34 和 tools/r8/r8-8.13.17.jar。安装包包含 arm64-v8a 语音运行库（Android 8.0+）；语音模型与第三方许可在 assets/voice、licenses/vosk。

AI 渠道密钥只通过构建参数注入临时副本，源码不含渠道密钥。发布签名文件由维护者本地保管，不随源码交付。首次从无凭据源码构建，可在 App 内配置个人 API 渠道；与现有安装覆盖签名一致需要原签名文件。

## 验证与范围

已执行 verify_v3130（解析、评分与来源逻辑）、verify_v3141（真实音长、10首内置谱、多音/倍速灯光播放）、verify_v3142（浏览器查询编码、链接协议、新站点与候选边界）及 verify_v3143/verify_apk.py（实际APK文件头/目录一致性、资源存储方式和模型完整性），并完成实际 APK 编译和签名校验。

华为 ADY-AL00 手机上已验证文字输入；用户确认语音恢复正常。实际测试《程艾影 赵雷》返回六个网页来源、可打开原谱，非文本谱不会被当作音符导入。它尚未得到可自动导入的完整曲谱。《欢乐颂》PDF 的 62 个音符及起拍位置与人工基准一致，试听结束、直接保存、进入跟弹及重启后保留均通过。《成都》照片的 247 个可见主旋律级数与人工基准一致；原音域超出部分被标记，整首升八度后可试听。该结果不代表任意照片的节奏、八度、装饰音都准确，导入前仍需校对。
