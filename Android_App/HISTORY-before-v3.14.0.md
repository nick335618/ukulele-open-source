# Ukulele Studio v3.13.1 / code 59

修复AI照片/PDF识谱完成后的试听与应用流程。基于3.13.0，其他识谱、曲库、乐趣、BLE、灯阵、音频分析与硬件协议保持原状。

- 试听状态直接显示在导入页，取消“开始/结束/停止”的连续Toast提示。
- “试听当前稿”在准备/播放时切换成“停止试听”，再次点击停止，结束后恢复。
- 文本/MIDI解析移到播放器工作线程；旧任务、旧12秒限时回调不能恢复/停止后一次试听。
- 自然结束或失败后撤销限时任务；12秒从播放器就绪后计时；关闭页面、进入后台或应用曲谱会停止试听。
- 有效曲谱的“核对并应用到曲库”始终可点击；未勾选核对时弹出明确确认，不再无提示灰掉。试听并非应用前提，可在试听前、中、后应用。
- 转录被修改、解析无效或正在保存时，仍会阻止应用旧结果。保存回调成功后才显示已保存。

覆盖安装App/Install/UkuleleStudio-v3.13.1-debug.apk，不用卸载旧版。保留原签名、曲库和设置。源码同目录build_apk.ps1默认3.13.1/59。

tools/verify_v3131/verify.py提供试听回归：实际播放器、PCM、时钟和MainActivity试听方法，Android音频/调度器采用测试替身；不是手机实测。旧导谱/评分回归仍在tools/verify_v3130。
原3.13.0功能与识谱边界见HISTORY-before-v3.13.1.md，详细本轮结果见App/Reports/照片识谱试听修复-v3.13.1.md。本轮未安装手机或验证实物。
