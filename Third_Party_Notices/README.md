# 第三方来源

随附依赖保持原库文件及可提取的许可证/NOTICE，另有Android_App/licenses。主要库包括Vosk、JNA、OpenCV、Kotlin、R8；本项目当前构建按实际导入决定是否打入某个库，不因源码目录中保留某库便宣称它在运行。

音效结构参考DaisySP，项目使用的定点串行RTL、状态调度与资源适配见Docs/Reference/开源音效参考.md。曲库来源和许可元数据保留在App资源及对应文档。模型、库和曲谱的权利说明随原文件保留，团队代码与第三方来源分开说明。

不随包复制Gowin、Arduino IDE、Android SDK或JDK安装目录；请使用各工具官方安装版本。


本次开源快照的软件和硬件默认许可范围见根目录LICENSES/README.md。Jar内嵌许可证已提取到Embedded_Jar_Notices；Vosk及模型、OpenCV和Kotlin许可亦保留在Android_App/licenses。自有MIT许可不覆盖第三方组件。
