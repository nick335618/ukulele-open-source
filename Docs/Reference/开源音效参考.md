# 开源音效结构参考

参考项目：https://github.com/electro-smith/DaisySP

固定提交：2c72eaf9eac5fc0dca1919d65d606da907832618。资料保存在开源参考/DaisySP，含原LICENSE和每个文件的SHA-256。该核心部分为MIT许可；未使用其独立LGPL子模块。

- Source/Effects/chorus.cpp：双引擎、调制延迟及混合结构。
- Source/Effects/flanger.cpp：延迟读数反馈、反馈量限制、干湿混合结构。
- Source/Effects/overdrive.cpp：非线性前的预增益与之后的电平管理。

本项目在这些结构思路基础上独立编写Verilog定点串行实现，针对已有1024×16RAM、共享ALU、单声道、无额外DSP的约束设计；不主张与原库逐样本相同或音色完全相同。原库C++不参与产品构建，引用快照供设计复核和许可证留存。

播放时钟依据Android AudioTrack的已消费音频帧接口：https://developer.android.com/reference/android/media/AudioTrack#getPlaybackHeadPosition()

ESP32 I²S扩展仅做过可行性核对，用户选择保持接线，本版没有实施：https://docs.espressif.com/projects/esp-idf/en/latest/esp32/api-reference/peripherals/i2s.html
