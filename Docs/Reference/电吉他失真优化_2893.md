## 更新与操作

本次只需更新新板FPGA/Flash/gv_host.fs，UserCode2893。保留App3.10.4、FX3版ESP32、当前屏幕及NVS设置；不改接线。旧板不得混烧。App中选择“电吉他失真”，从较低混合量逐渐调至127比较。该滑块仍是原声/失真的连续混合量0..127，不是另加一套独立Drive/Tone控件。

## 声音如何改变

输入 → 低频整理 → 32倍预驱动与包络限制削波 → 高频整形 → 3/4电平补偿 → 原声/失真交叉混合 → 饱和保护 → I²S。

低频整理利用一阶低通状态得到高通分量，系数1/32，理论小信号截止约247Hz；削波前减少低频占用，使中高频更突出。预驱动由8倍改32倍，输出幅度仍参考近期信号包络。包络释放由约5.2ms改约21ms（大信号近似时间常数，小信号每样本至少衰减1LSB），增强衰减阶段的饱和保持，既不修改两套物理音色ROM，也不把原包络强制改为ADSR。

后级一阶低通由系数1/4改1/2，理论截止约5.62kHz，保留更多失真上谐波，同时限制最高频率。它是高频音色整形，不宣称完整移植真实吉他音箱或多级踏板。随后乘96/128作输出电平补偿，再与原声混合；避免仅靠响度制造效果。整体仍是单声道，原调制音效保持。

算术操作继续复用原18位串行ALU和逐位乘法器。mode4借用phase寄存器保存输入滤波状态、借用chorus_second保存高通样本符号；这些寄存器在其他模式恢复原用途。把调制相位和RAM写指针增量也并入同一ALU，省去并行加法器；后级3/4补偿复用插值乘法状态。模式切换仍先淡出、清除效果内部状态再淡入，原有发声引擎与尾音不被清空。

## 量化对照与试听

500-LSB、1kHz测试音的实际RTL结果：

|指标|6604|2893|
|---|---:|---:|
|三次谐波相对基频|−13.60dBc|−10.79dBc|
|五次谐波相对基频|−21.34dBc|−16.36dBc|
|七次谐波相对基频|−27.64dBc|−21.17dBc|

在同一测试旋律上，2893均方根电平只比6604高约0.28dB。单一测试音、不同旋律和不同混合量的电平不会完全相同；这里既提供原幅度文件，也提供等响度文件，便于单独评估音色。

Audio_Demos/distortion-dry-6604-new-equal-loudness.wav依次是原声、6604、2893，中间停顿；distortion-6604-new-equal-loudness.wav直接比较两版失真。音频来自实际RTL对合成拨弦旋律的处理，不是整机录音，也不代表两套物理音色所有音符的实物听感。

## 保留内容、资源与验证

唯一功能源码修改为src/audio_fx.v；16个ROM内容、12动态声部、每声部最多60弦模态、8共享琴体模态、48,828.125Hz采样率全部保持。ADC、触摸、滑音颤音、演奏模式、LED/曲谱、BLE、波形频谱、休眠及20%上电音量源码未改。0x21/0x8D v3和BLE FX3协议、范围、真实回读及NVS结构均保持。

器件GW5A-LV25MG121NC1/I0。实际布局布线：Logic22810/23040、Register10632/23280、CLS11502/11520、BSRAM56/56、DSP28/28。50MHz Setup/Hold均零违例，最小裕量+0.647ns/+0.145ns。新增DSP和RAM均为零；资源仍接近上限，后续改动必须重新布局布线。

260000实际RTL样本的2080000个参考值比较、330000样本拨弦/脉冲测试、36000样本其他效果回归均通过。所有效果在64个主时钟内完成，生产采样间隔1024时钟。静音尾段严格为零。实际顶层I²S解码3994字逐字匹配最终PCM，包含旁路和新版失真；传感器音色引擎输出位置在该项中注入已知PCM。

综合日志仍有原工程的位宽/ROM文本宽度及优化提示，并非零警告构建。ROM高位填零格式与内容未改；失真滤波差值先18位计算后饱和到16位。日志中CHORUS_SUM的17→16位截取用于两路16位样本平均，其结果必在16位范围内。未修改这些提示以伪造无警告结果。
