# 本轮协议

## 实际音符反馈

FPGA→ESP32 的 `0x84` 载荷仍为 30 字节。原光电 raw/dg、事件位图、指法、实际 MIDI 和每弦计数位置不变。

| 载荷偏移 | 内容 |
| --- | --- |
| 0～7 | 四路原始光电值，小端 16 位 |
| 8～15 | 四路处理后光电值，小端 16 位 |
| 16 | 原光电事件位图 |
| 17 | 低四位协议版本 2，高四位为四路最后一次实际发声的自动来源标志 |
| 18～21 | 实际触摸品位 |
| 22～25 | 实际送入音频引擎的 MIDI |
| 26～29 | 四路累计发声计数，8 位回绕 |

以上四路顺序为 G/E/C/A。来源标志跟随每路最后一次发声，只有计数变化才表示新事件。真人拨弦清除对应路自动来源位，其他路保持。自动音符和真人音符共用原音频分配通路。

ESP32 兼容旧 `0x84` 17 字节与 30 字节版本 1。BLE `0xA1` 仍为 20 字节，兼容默认 23 字节 MTU。版本字节为 2，偏移 16 低四位保留光电事件，高四位携带自动来源；其余字段位置不变。新版 App 同时接受版本 1 和 2，版本 1 的高位仍要求为 0。

App 使用音符计数更新当前音名，按来源过滤录奏和评分。不能将来源位图单独解释为新音符。

## 只读电容及颤音诊断

请求 `0x22` 三字节，依次为版本、通道、令牌。通道范围 0～96，主电极 0～71，辅助电极 72～96，映射沿用现有通道表。

版本 1 返回 `0x8E` 12 字节，与原诊断兼容。版本 2 返回 20 字节。

| 版本 2 载荷偏移 | 内容 |
| --- | --- |
| 0、1、2 | 版本 2、通道、令牌 |
| 3 | 有效/触摸/配置等标志，沿用版本 1 |
| 4～5、6～7、8～9 | raw、baseline、delta，小端 16 位 |
| 10、11 | 芯片状态、配置完成 |
| 12 | 实际手势使能位 |
| 13 | 低四位各弦颤音活动，第4位音频颤音门控，第5位颤音调制电平，第6位归属有效，第7位滑音活动 |
| 14 | 颤音归属弦，A/E/C/G = 0/1/2/3 |
| 15～16、17～18 | 内部幅度、实际门限，小端 16 位 |
| 19 | 实际音色 0～3 |

ESP32 控制台 `PAD:0`～`PAD:96` 请求对应诊断，`GESTURE_STAT` 查询手势设置。诊断不注入拨弦、不改变触摸阈值。帧长、版本、边界和 XOR CRC 验证通过后才更新镜像。
