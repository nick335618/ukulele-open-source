# 屏幕 ↔ ESP32 通信协议 v1（115200）

## 1. 目标

屏幕负责显示和触摸操作，ESP32 负责协议转换、参数镜像、保存和状态聚合，FPGA 继续使用现有 `0x08/0x0A/0x0B/0x0C` 命令。

屏幕协议不直接暴露 FPGA 的帧格式，后续把触摸电容、光电管、声音状态加入页面时，只扩展屏幕 ↔ ESP32 的消息类型。

串口：115200 8N1，ESP32 TX=GPIO22，RX=GPIO21，共地。

## 2. 帧格式

```text
A5 5A VER TYPE SEQ LEN_L LEN_H PAYLOAD... CRC_L CRC_H
```

| 字段 | 长度 | 说明 |
|---|---:|---|
| `A5 5A` | 2 | 固定同步字；接收端丢弃直到重新找到同步字 |
| `VER` | 1 | 协议版本，当前为 `0x01` |
| `TYPE` | 1 | 消息类型 |
| `SEQ` | 1 | 请求序号；响应复制请求序号 |
| `LEN_L/H` | 2 | 载荷长度，小端，最大 256 |
| `PAYLOAD` | LEN | 载荷，小端数值 |
| `CRC_L/H` | 2 | 从 `VER` 到 `PAYLOAD` 的 CRC-16/CCITT-FALSE |

接收端按长度收帧并校验 CRC；CRC 错误只丢当前帧，继续寻找下一个 `A5 5A`。所有修改类请求都必须返回 ACK 或 NACK，不能静默失败。

## 3. 屏幕 → ESP32 请求

| TYPE | 名称 | 载荷 |
|---:|---|---|
| `0x01` | `GET_SNAPSHOT` | 无；请求完整状态 |
| `0x02` | `SET_CHANNEL` | `ch:u8, threshold:u16, gain:u8` |
| `0x03` | `SET_GLOBAL` | `pid:u8, value:u32` |
| `0x04` | `LOAD_PRESET` | `preset:u8`，0 灵敏、1 均衡、2 抗误触、3 抗环境光 |
| `0x05` | `SAVE_CONFIG` | 无；保存到 ESP32 NVS |
| `0x06` | `LOAD_CONFIG` | 无；从 NVS 读回并下发 FPGA |
| `0x07` | `DEFAULT_CONFIG` | 无；恢复抗误触默认值 |
| `0x08` | `SET_FIRST_LOCK` | `window_ticks:u32`，50 MHz 下 50000 约为 1 ms |
| `0x09` | `SET_VOLUME` | `volume:u8`，0..100 |
| `0x0A` | `SET_TIMBRE` | `timbre:u8` |
| `0x0B` | `PING` | 无 |

### 通道编号

```text
ch 0 = G 弦 / ADC0
ch 1 = E 弦 / ADC1
ch 2 = C 弦 / ADC2
ch 3 = A 弦 / ADC3
```

`SET_CHANNEL` 必须由 ESP32 用当前镜像补齐另一项参数，再转换成 FPGA 的 `0x08`，避免只改阈值时把增益清零。

## 4. ESP32 → 屏幕响应

| TYPE | 名称 | 载荷 |
|---:|---|---|
| `0x80` | `ACK` | `original_type:u8, result:u8` |
| `0x81` | `NACK` | `original_type:u8, error:u8` |
| `0x82` | `SNAPSHOT` | 见下表 |
| `0x83` | `NOTE_EVENT` | `ch:u8, fret:u8, velocity:u8, note:u8, timestamp:u32` |
| `0x84` | `LINK_STATUS` | `fpga_online:u8, parameter_valid:u8, age_ms:u16` |

### `SNAPSHOT` 载荷

```text
raw0..raw3       u16 × 4   原始光电值
dg0..dg3         u16 × 4   增益后检测强度
event_mask       u8        最近一帧触发位
first_channel    u8        本次第一根弦，255 表示无触发
threshold0..3    u16 × 4
gain0..3         u8  × 4
slow             u32
fast             u32
cm_cap           u32
margin           u8
persist          u8
cool             u16
blank            u32
rearm            u16
first_lock       u32
```

屏幕刷新建议 5~10 Hz；触发事件使用 `NOTE_EVENT` 立即刷新，不能只依靠慢速快照。

## 5. 错误码

```text
0x01  未知 TYPE
0x02  载荷长度错误
0x03  参数超范围（ESP32 应拒绝，不静默截断）
0x04  FPGA 链路暂时不可用
0x05  NVS 保存失败
0x06  参数正在下发，稍后重试
0x07  CRC 错误
```

## 6. 屏幕功能页面

### 主页面

- 当前音量、音色、当前音名。
- FPGA/ESP32 在线状态。
- 最近一次拨弦的弦、品位和力度。

### 光电调节页面

- 四行 G/C/E/A 状态：`raw`、`dg`、阈值、增益、触发指示。
- 每行阈值 `+/-` 和增益 `+/-`。
- 四个预设：灵敏、均衡、抗误触、抗环境光。
- 首事件锁定窗：关闭、0.5 ms、1 ms、2 ms。
- 当前参数刷新、保存、载入、恢复默认。

### 高级参数页面

放置 `slow/fast/cm_cap/margin/persist/cool/blank/rearm`，并显示每个参数的单位和允许范围。普通演奏者不需要进入此页。

## 7. 必须遵守的行为

1. 调参即时生效，但只有点击“保存”才写入 NVS。
2. 预设加载后必须等待 ESP32 返回 `SNAPSHOT`，页面显示实际值，不只改变按钮样式。
3. FPGA 断链时停止发送“已成功”的提示，保留最后值并显示离线。
4. `first_lock` 当前需要 FPGA 增加回读字段；在此之前屏幕可以显示 ESP32 镜像，但应带 `parameter_valid` 状态。
5. 屏幕不要直接计算 FPGA CRC，也不要直接拼 FPGA 命令；所有数值校验和范围限制由 ESP32 完成。
