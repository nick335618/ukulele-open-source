## 已有最新修复

MIDI可整体升降八度，支持低把位或换弦练习指法；实际音高与起音时刻保持对应，元数据随曲目保存。自动播放实际发声事件回传App，自动事件不计入真人评分与录奏。设备播放的三秒倒计时支持App内部切页，断线、退后台、停止和换曲仍有取消保护。

## 已知边界

- 颤音在不同弦、品位的触发一致性仍待校准。代码包含品格与辅助电容两种判定、可调门限及97路只读诊断，不能把已实现调制通路等同于手感问题全部解决。
- 当前音高手势归属最近一次有效真人拨弦对应声部，未实现所有声部各自独立的同时揉弦。
- 最差Setup裕量0.008 ns，Fmax50.020 MHz；SDC尚未完整补齐板级外设I/O延迟约束。再次改动必须重新检查完整布局布线。
- 电量格数依据电池电压估计；充电状态依赖对应硬件输入，未将电压估计当作精密库仑计量。
- 频谱、波形、XY为最终数字PCM的分块观察，未测量DAC模拟端；4096点FFT采集窗本身约84 ms。显示传输刷新率不同于音频输出采样率。
- PDF／照片识谱是辅助导入，复杂谱、符号与节奏需人工校对；网络AI需用户配置通道并遵守来源权利。
- 新提供的PCB与3D作为当前硬件设计源文件公开，其与软件的实物适配仍以实际接线、制造版本和测试为准，本次归档不产生新的上板验证结论。
