# 整机装配与3D打印结构

本目录由团队2026年11月21日提供的Uke-V2.rar原样展开。原始RAR另在[发布页](https://github.com/nick335618/ukulele-open-source/releases/download/open-source-2026-11-21/Uke-V2.rar)保留，文件校验见根目录SHA256SUMS与发布页校验清单。

除一个SolidWorks临时锁定文件外，共217个文件，包含原生零件、装配和一个STEP参考文件。保留原始中文名称和文件夹关系。

| 目录／入口 | 用途 |
|---|---|
| [总成/装配体1.SLDASM](Uke-V2/总成/装配体1.SLDASM) | 整机总成入口 |
| [拼装/琴.SLDASM](Uke-V2/拼装/琴.SLDASM) | 整体拼装入口 |
| [总成/外壳上.SLDPRT](Uke-V2/总成/外壳上.SLDPRT)、[外壳底](Uke-V2/总成/外壳底.SLDPRT) | 外壳结构 |
| [总成/骨架.SLDPRT](Uke-V2/总成/骨架.SLDPRT) | 内部承力／装配骨架 |
| [总成/底座.SLDPRT](Uke-V2/总成/底座.SLDPRT) | FPGA与ESP32集成安装位置 |
| [总成/琴颈.SLDPRT](Uke-V2/总成/琴颈.SLDPRT) | 琴颈结构 |
| 主板、琴弦、琴箱、琴颈子目录 | 分模块装配与器件参考 |
| [琴箱/骨架参考.STEP](Uke-V2/琴箱/骨架参考.STEP) | 中性格式参考模型 |

外壳和结构采用3D打印。原文件以SolidWorks格式为主，不是已切片的打印任务；请自行导出STL/3MF并按材料、设备和装配公差配置工艺。装配中还包含开发板、扬声器、电子元件等第三方参考模型，其权利与许可按原作者保留。

打开装配若提示引用缺失，请先保留完整目录，再将Uke-V2及子目录设置为模型搜索路径，避免只下载单个装配文件。
